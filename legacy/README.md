# Legacy

Archiv der früheren Prototypen. Diese Dateien gehören nicht zur öffentlichen App und werden vom Build nicht ausgeliefert.

- `clickdummy/` – früher Clickdummy (Shop-Ablauf und Befindlichkeitsauswahl)
- `webhook-formular.html` – früheres Formular an einen externen Dienst

Die Texte sind historisch. Für die Vorschau gilt die Vite-App im Repository-Root: Geschmack und Tageszeit, ohne Shop und ohne Gesundheits- oder Heilaussagen.
